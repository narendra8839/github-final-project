# Simple Interest Calculator

## Description
This project calculates the simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual rate of interest in percentage.
- **Time (T):** The time period in years.

## Example
Suppose the principal amount is ₹10,000, the annual interest rate is 5%, and the time period is 2 years.

Simple Interest = (10000 × 5 × 2) / 100 = ₹1,000

Therefore, the simple interest is ₹1,000.

## Purpose
This project demonstrates the basic calculation of simple interest and introduces the use of GitHub for project documentation.
